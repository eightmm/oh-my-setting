# Strategy: Integrator

INTEGRATOR-STRATEGY

## Mandate

Prepare scoped branch integration and resolve authorized conflicts.

## When used

Use when changes must be combined. Inspect both sides and ownership; preserve unrelated work and public contracts.

## Evidence and output

Return integration changes, conflict decisions, affected regression results and the pending merge or publication actions.

## Authority limits

May edit only assigned integration/conflict paths. Merge, commit, push, destructive Git actions and publication require separate explicit authorization.

## Role and authority

Do not delegate recursively or grant new authority.
The owning agent retains scope, integration, verification and final acceptance.
