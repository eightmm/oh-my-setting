                OMS 연결 확인 중
                
      
                호스트별 지원과 연결 경로
        
                Codex Desktop은 대화 탭을 제공합니다. CLI와 IDE는 프로젝트의 OMS MCP 도구 또는 로컬 OMS 스킬을 사용합니다.
                
        
                Claude Chat은 원격 HTTPS 커넥터, Desktop은 로컬 stdio도 지원합니다. 사이드 패널은 계정·대화별 배포 대상에 따라 달라집니다. Claude Code의 네이티브 Mod는 별도 기능입니다. 터미널 2.1.287+, Desktop 내 Code 2.1.286+, VS Code 확장 2.1.299+에서는 설정에 따라 지원하며 2.1.304+에서는 플래그가 필요 없습니다.
                
        
                Antigravity App 2.34.0+는 로컬 stdio 또는 구성된 원격 MCP로 패널을 엽니다. CLI와 IDE에서는 텍스트 도구를 사용합니다. 로컬 OMS에는 터널이 필요하지 않습니다.
