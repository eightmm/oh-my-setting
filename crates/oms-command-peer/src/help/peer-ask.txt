Usage: peer-ask.sh [options] --prompt TEXT

Ask the same question to a provider council, then persist each answer as an
artifact. The default council is Codex, Claude Code, and Antigravity. Default
mode is concept/question only; no repo context is attached unless requested.

Options:
  --prompt TEXT        Question/task. Required.
  --hypothesis         Pre-registration design review: inject an
                       attack-the-design checklist (falsifiability, confounds,
                       baseline fairness, split/leakage, metric fit, variance)
                       into every advisor prompt. Pass the hypothesis and the
                       planned experiment as the prompt (--prompt or positional).
                       Use before expensive runs.
  --repo PATH          Git repo for optional context. Default: current directory.
  --providers LIST     Comma list of registered targets. Default: the stable
                       Codex/Claude/Antigravity council; optional agents are
                       available when explicitly named.
                       An entry may carry a model (codex:model=NAME) to pin it.
                       Before :model=, :effort=E sets that seat's effort. Use
                       :effort=auto for the model's default, including fixed-effort models.
                       Append :optional to tolerate a failed seat; at least one seat must be required.
                       Answers from one provider share a model family, which
                       the reported family count makes explicit.
  --artifact-dir PATH  Artifact directory. Default: REPO/.oms/artifacts/ask.
  --model MODEL        Exact model; requires exactly one provider.
  --fallback-model M   One-shot capacity fallback; requires one provider.
  --account ID         Run on a registered codex, claude or pi account (also
                       PROVIDER:account=ID); requires exactly one provider.
  --reasoning-effort E auto, low, medium, high, xhigh, max, or ultra.
  --repo-context       Attach sanitized git status only.
  --diff               Attach sanitized git status and diff.
  --memory             Attach shared harness memory.
  --task               Attach the active task handoff packet.
  --ml-context         Attach the compact ML context digest.
  --no-memory          Disable --memory (compatibility).
  --no-task            Disable --task (compatibility).
  --no-ml-context      Disable --ml-context (compatibility).
  --thread ID          Publish each completed answer to a shared thread (create
                       if absent). Later rounds share a bounded notes snapshot.
                       Providers receive bounded prior thread context initially.
  --no-current         Append to an existing explicit --thread without selecting
                       it as the repository foreground thread.
  --deliberation       Require evidence, alternatives, counterargument and checks
                       from every seat; task JSON alone is not a deliberation.
                       Requires --debate; implies --require-complete.
  --require-complete   Fail unless every required seat completes the final round.
                       Partial quorum remains available without this flag.
  --synthesize TARGET  Add one advisory synthesis with the selected provider/model.
  --synthesis-json     Emit schema-1 oms-council-synthesis instead of human text.
                       Requires --synthesize with an exact model and
                       --require-complete. For rebuttals, add both --debate
                       and --deliberation; omitting both uses initial answers.
                       One required seat
                       per provider; all declared rounds must complete. Enforces
                       nonempty evidence/counterargument/verification sections
                       and synthesis Decision/Evidence/Remaining disagreements/
                       Verification sections. Binds request, run, rounds and
                       artifact/output bytes by SHA-256. Requested models do not
                       prove served models or independent reasoning. Missing,
                       refused or malformed output fails; no automatic restatement.
                       Existing text and --json modes are unchanged without it.
  --debate N           Add N debate rounds (1-3). Each round, every provider
                       sees the others' previous answers, critiques them, and
                       revises its own. Repo context is in round-1 prompts;
                       later calls receive bounded positions, evidence and
                       deltas, plus references to shared initial context and
                       sanitized answer copies. All seats share
                       OMS_DEBATE_ROUND_BYTES (default 65536, excluding native
                       provider context). The debate stops early when every
                       seat declares "none" under "Changed from previous
                       round:" — stability, not consensus: recorded
                       disagreements stand.
                       Native OMS opening/rebuttal calls use at most four active
                       seats; completed thread turns publish without waiting
                       for slower seats. Every started call is joined on error.
                       Linux seats keep isolated whole-tree supervisors.
                       Embedded executors run serially unless their host
                       explicitly supports concurrent child cleanup.
  --until-agreement    Opt-in: debate until every answering seat (at least two)
                       shares one Verdict:/Recommendation:/Answer: line, or the
                       cap is reached. Replaces --debate; incompatible with
                       blind lens seats. Agreement is a tally of identical
                       lines, not correctness; cost scales with rounds. A seat
                       that fails stops the loop (no retry). The synthesis
                       records rounds run, the stop reason (agreed, cap
                       reached, seat failed) and who changed per round.
  --max-rounds N       With --until-agreement: round cap, 1-6 (default 4).
  --export-only        Write provider prompt artifacts and do not call CLIs.
                       Use when the current agent may not send repo context to
                       another external provider. Import answers later with
                       `oms artifact-index import`.
  --print-timeout DUR  Pin a fixed wall-clock timeout (also passed to agy print
                       mode). Unset default: streaming providers (codex, claude,
                       pi) use a 20m stall check + 24h cap; non-streaming
                       providers (agy print mode, aider, others) use a 15m wall.
  --dry-run            Write prompts as artifacts without CLI calls.
  -h, --help           Show this help.

Environment:
  OH_MY_SETTING_ASK_DRY_RUN=1   Same as --dry-run.
  OMS_PEER_TIMEOUT       Pin a fixed per-provider wall-clock timeout. Unset by
                         default: streaming providers (codex, claude, pi) use
                         OMS_PEER_STALL + a 24h cap; non-streaming providers
                         (agy print mode, aider, others) use a 15m wall.
  OMS_PEER_STALL         Stop a streaming provider (codex, claude, pi) after DUR
                         with no stdout/stderr output (default: 20m; 0 disables).
                         Also covers one silent turn or long silent tool call;
                         raise OMS_PEER_STALL for quiet steps or set
                         OMS_PEER_TIMEOUT to pin a fixed wall instead.

Exit: 0 when required quorum answers (at least one answer, or every required
seat with --require-complete/--deliberation); 124 when the run fails and every
failed required seat hit a stall or wall deadline; 1 on other seat failures; 2
on usage errors.

Team report channel (explicit opt-in):
  --team-requests --providers ADAPTER --team-id ID --team-spec-sha256 SHA
  --team-member LEAD --team-member-generation N --task-id TASK
Requires one registered custom read adapter and an owned, single-link manifest
ADAPTER.oms-team-request-v1.json that is not group/other writable. It contains
schema 1, protocol oms-team-request-v1, and binary_sha256. Built-in transports
are unsupported. The native parent authenticates its actual owned stdio
session; flags and manifest grant no controller credential. Only report_blocker
is enabled by default; no task-state change, dispatch, wakeup, or automatic resend.
  --team-request-actions LIST  Explicit report_blocker/propose_tasks allow list;
                               requires --team-requests. No other action is supported.
propose_tasks records a bounded decomposition for parent review. It does not add
tasks or select verifiers/routes. Read retained requests with
`oms agent-plan team-show --id ID --requests`.
