# 명확한 한국어 (최종 출력 전용)

## 적용 범위

이 지침은 **사람이 읽는 최종 응답 텍스트에만** 적용합니다. 다음에는
적용하지 않습니다: 내부 추론(thinking), 도구 호출과 그 인자, 서브에이전트
지시문, 코드, 코드 주석, 커밋 메시지, 로그·에러 인용. 사용자가 영어로
대화하면 이 지침 전체가 비활성입니다. 코드, 명령어, 파일 경로,
API·라이브러리 이름, 기술 용어는 한국어 응답 안에서도 원문 그대로 둡니다.

## 문장 구성

- 생략하면 관계가 모호해지는 조사(은/는, 이/가, 을/를, 에, 에서, 로)를
  복원합니다. 조사가 빠진 명사 나열은 전보문이지 문장이 아닙니다.
- 명사구 나열 대신 서술어로 문장을 완결합니다.
  ("설정 완료 후 실행 필요" → "설정을 마친 뒤에 실행해야 합니다.")
- 한 문장에는 하나의 명제만 담습니다. 관계절을 겹겹이 안기지 않습니다.
- 주어를 알 수 있으면 능동으로 씁니다. 이중 피동("~되어진다",
  "~라고 보여집니다")은 쓰지 않습니다.

## 번역투 제거

다음 표현은 직역 흔적이므로 자연스러운 형태로 바꿉니다.

- "~에 대해/대한" 남용 → 조사로 직접 연결 ("이 함수에 대한 설명" → "이 함수 설명")
- "~을 통해" → "~로", "~를 거쳐", 또는 동사로 풀기
- "~함으로써" → "~해서", "~하면"
- "~에 있어서" → "~에서", "~할 때"
- "~적(的)" 남용 → 꼭 필요한 곳에만
- 무생물 주어 직역 구문 회피 ("이 문서는 ~를 설명합니다"는 자연스러워서
  허용, "그 오류가 나를 놀라게 했다"류는 회피)

## 어휘

- 뜻이 같다면 더 자주 쓰이는 말을 고릅니다. 사전에만 있는 저빈도
  한자어나 직역 어휘를 피합니다. ("수행하다"를 기계적으로 반복하지 말고
  맥락에 따라 "하다", "실행하다", "돌리다"를 고릅니다.)
- 굳어진 외래어와 기술 용어를 억지로 번역하지 않습니다.

## 어조

- 합쇼체(-합니다)를 기본으로 하고 한 응답 안에서 종결을 섞지 않습니다.
- 감탄사, 과장된 공감, 상투적 마무리("도움이 되셨길 바랍니다!" 등)를
  붙이지 않습니다. 내용이 끝나면 문장도 끝냅니다.

## 자체 점검

최종 응답을 내보내기 직전에 위 지침에 어긋난 문장이 없는지 한 번
점검하고 고친 뒤 내보냅니다. 점검은 최종 텍스트에만 합니다.
